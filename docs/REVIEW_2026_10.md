# October 2026 code review

The review covers the current synthetic experiment, language-foundation interfaces,
multimodal processing, finite-candidate planning and checkpoint evidence. The original
reference metrics, weights, manuscript tables and pretrained integration record are
historical evidence and are preserved.

| Finding | Implemented correction | Regression evidence |
|---|---|---|
| Multi-window foundation rollout repeatedly supplied unchanged observation ages | Require an explicit macro duration for multi-window multimodal forecasts; age a fixed snapshot at each boundary without mutating caller inputs | Agreement with manually advanced windows; difference from frozen-age forecasts; preference invariance |
| Old measurements had no explicit expiry policy | Optional per-modality age limit masks expired tokens and graph edges | Exact boundary, expired-node isolation, and zero gradient through expired features |
| Clamping graph degree to one attenuated fractional edge weights | Normalize all nonempty rows by their actual degree; leave isolated rows at zero | Same messages under global edge rescaling, including weights below one |
| Masked text IDs were still embedded; oversized semantic input could trigger an unnecessary physical pass first | Replace masked IDs before lookup; preflight both language-model input budgets | Masked invalid IDs accepted; valid invalid IDs rejected; over-budget requests make zero decoder calls |
| Valid power caps below the minimum grid action crashed planning | Use a zero-power fallback when the filtered grid is empty | Caps of 0.001, 0.1 and 0.199 remain feasible; the default benchmark grid is unchanged |
| Checkpoint verification omitted most deterministic metrics and accepted NaN differences | Compare the complete metric tree with finite-number and schema checks; validate run coverage and checkpoint metadata | Corrupted vectors, missing keys, non-finite values and incomplete run grids fail |
| Recursive source hashing included a locally installed `.venv` | Restrict provenance to project source locations | Virtual-environment and generated-run Python files excluded |
| Repository lint failed on the patent exporter added after the original experiment | Apply import sorting and formatting to the exporter | Repository-wide Ruff checks; no patent document regeneration |

The verification command retains strict source matching by default. `make verify`
explicitly selects cross-revision regression so maintained code can be checked against
the original checkpoints while recording source differences. Fresh smoke checkpoints
are verified with strict source matching. Neither mode replays training or compares
wall-clock timings.

Validation on Python 3.12 / PyTorch 2.5.1 CPU:

- All 64 tests pass, including an offline Qwen2 transformer integration.
- Repository-wide Ruff lint and formatting checks pass.
- All 24 historical variant/seed rows match across 1,560 deterministic metric values
  at absolute tolerance `1e-5`; see `results/review_checkpoint_verification.json`.
- Fresh two-update training for all eight variants saves and strictly re-verifies
  checkpoints across 520 metric values.
- Regenerated benchmark summary values agree with the committed summary.
- The patent exporter's syntax tree is unchanged apart from import ordering.

Observation expiry improves input handling; it does not implement packet transport,
clock synchronization, calibrated freshness limits, or a deployed fallback controller.
The zero-power planning fallback is specific to this simulator's nonnegative power
budget and is not a general network safety guarantee. These changes do not establish
improved real-radio accuracy or language-foundation RAN training performance.
